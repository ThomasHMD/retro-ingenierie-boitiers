# Voie de secours : CONFIG › Version du firmware (écran 105) › Version/MAJ (écran 106, « Mise à jour ? »),
# depuis chacun des 4 onglets sur lesquels le menu peut rouvrir. S'arrête sur la question, sans répondre
# Oui : rien n'est écrit. À chaque étape : écran attendu (pointeur de menu 0x83CEE49C), mode menus,
# et sur les écrans 105 et 106 des pixels de l'écran Nikon d'origine (colonne des onglets, titre,
# barre), les mêmes quel que soit le firmware : l'étape 5 (onglets en bandeau) y rend la main au code
# Nikon sans rien changer. Y du point (x, y) = 0x83BD6510 + 640 y + x.
# L'émulateur n'a pas de carte : « retour 0xAB5CC 1 » fait répondre à maj_chercherFichiers qu'un
# BD40….BIN est sur la carte (sans quoi Version/MAJ n'apparaît pas), et 0x83CE950C = 0xC0
# (accumulateur plein) laisse passer le contrôle de l'alimentation d'ecran105_action.
# Navigation commune aux deux firmwares (octobre 2026) : « onglet n » pour changer d'onglet, OK pour
# entrer, ▼ pour descendre jusqu'à Version du firmware (▲ en haut d'une liste de tête ne boucle plus en bas
# avec la navigation du bandeau).
#   python3 emulateur/d40emu.py scenario secours --firmware build/v1/BD400111.BIN --style tous
run 1M
poke8 0x83CED0FC 0x18          # français
run 69M
retour 0xAB5CC 1               # maj_chercherFichiers : un fichier de mise à jour est sur la carte
press menu 4M 30M
expect16 0x83CED23A 0x0005     # mode menus
# réglages à zéro dans l'émulateur = menus « simples », sans Version du firmware :
# CONFIG › Menus › Complet (la seule option du menu Pip-Boy)
press left 4M 16M
onglet 0x03
press ok 4M 20M                # entrer dans la liste (▶ chez Nikon ; OK marche avec les deux navigations)
expect16 0x83CEE49E 0x69AC     # liste CONFIG
jusqua8 0x83CE69BB 0x00 up 20
jusqua8 0x83CE69B9 0x00 up 10
press right 4M 20M
expect16 0x83CEE49E 0x733C     # écran Menus
press ok 4M 30M
expect16 0x83CEE49E 0x69AC     # liste CONFIG, complète
# ---------- menu rouvert sur PRISE DE VUE
press left 4M 16M
onglet 0x01
press menu 4M 30M              # sortie du menu
press menu 4M 30M              # retour : le menu rouvre sur l'onglet mémorisé
expect16 0x83CED23A 0x0005
expect8 0x83CE3FE8 0x01
